# 🌐 Personal Website

This repository contains the source code for my personal website. The site is built with React + Vite, deployed behind Cloudflare for security and performance, and hosted on my own server.

## 🚀 Tech Stack

| Technology | Purpose |
|---|---|
| React | Frontend framework |
| Vite | Build tool and development server |
| Cloudflare | DNS, CDN, SSL, and security |
| Self-hosted server | Production hosting |
| Node.js | Build environment |
